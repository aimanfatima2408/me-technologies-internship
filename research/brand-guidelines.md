# ME Technologies — Brand Guidelines

## 1. Company Logo

The original company logo is saved in the brand-assets folder.

## 2. Brand Colors

- Primary Color: Green
- Secondary Color: Yellow
- Background Color: Black

## 3. Website Design Notes

The website should use colors that match the company's existing branding. The design should be clean, professional, easy to navigate, and readable on both desktop and mobile screens.

## 4. Logo Usage

The company logo should be displayed clearly in the website header and should maintain its original proportions.

## Brand Colors

- **Primary Green:** `#059445`
- **Secondary Green:** `#54CC1C`
- **Yellow:** `#FFD22F`

These three colors were identified from the original ME Technologies logo. They will be used consistently throughout the website to match the company's branding.

## Logo Version and Usage 
- **Original Logo:** The original company logo is kept unchanged for refrence.
- **Transparent Logo:** Used where the logo needs to appear without a background.
- **White Footer Logo:** Used on dark backgrounds, such aas the website footer.
- **Favicon:** A square version of the logo will be created for browser tabs and mobile devices.

The logo files are stored in the research/brand-assets folder. The favicon files will be added after they created.
